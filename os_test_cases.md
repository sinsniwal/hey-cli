# hey-cli OS Test Cases

This document contains specialized natural language test cases designed to test the conversational context parser and OS rule heuristics (GNU vs BSD vs Windows).

## macOS (Darwin)
1. "delete all files in this directory with a .tmp extension" (Should use `find . -name '*.tmp' -delete` or `rm`)
2. "replace 'foo' with 'bar' in config.json" (Must use `sed -i '' 's/foo/bar/g' config.json`, avoiding GNU sed errors)
3. "count how many lines match the word 'error' in all logs" (Must avoid `grep -P`)
4. "list all running processes and count them" (Testing `ps aux | wc -l`)
5. "flush the dns cache" (macOS specific: `sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder`)
6. "show me my local ip address" (macOS specific: `ipconfig getifaddr en0`)
7. "tell me what my default gateway is" (`route -n get default`)
8. "turn off the wifi" (`networksetup -setairportpower en0 off`)
9. "print out all the directories here on one line separated by spaces" (Testing `xargs` without GNU `-d`, using `tr '\n' ' '`)
10. "eject the connected usb drive" (`diskutil eject /Volumes/...`)

## Linux (Ubuntu/Debian)
1. "replace 'foo' with 'bar' in config.json" (Must use standard GNU `sed -i 's/foo/bar/g' config.json`)
2. "find all files ending in .log and remove them" (`find . -name '*.log' -print0 | xargs -0 rm`)
3. "show me my local ip address" (`hostname -I` or `ip addr show`)
4. "reboot the system immediately" (`sudo reboot now`)
5. "check what service is using port 80" (`sudo lsof -i :80` or `sudo netstat -tulpn | grep :80`)
6. "install the htop package" (`sudo apt-get install htop`)
7. "flush the dns cache" (Linux specific: `sudo resolvectl flush-caches` or `sudo systemd-resolve --flush-caches`)
8. "tell me the operating system release version" (`cat /etc/os-release`)
9. "print the files separated by commas" (Can safely use GNU `xargs -d '\n'` or `paste -sd,`)
10. "extract this tarball archive" (`tar -xzf <file>`)

## Windows (PowerShell)
1. "show me my ip address" (`ipconfig`)
2. "list the contents of this directory" (`Get-ChildItem` or `dir`)
3. "kill the process using port 8080" (`Stop-Process -Id (Get-NetTCPConnection -LocalPort 8080).OwningProcess -PassThru`)
4. "create a new folder called test" (`New-Item -ItemType Directory -Name test`)
5. "find all text files containing the word error" (`Select-String -Path *.txt -Pattern "error"`)
6. "flush the dns cache" (`ipconfig /flushdns`)
7. "show me running docker containers" (`docker ps`)
8. "what is the current time" (`Get-Date`)
9. "download a file from a url" (`Invoke-WebRequest -Uri <url> -OutFile <file>`)
10. "unzip this compressed folder" (`Expand-Archive -Path <file> -DestinationPath <dir>`)
